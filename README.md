# The Most Honest Outage Line

One status-page line (142 characters) for the make.fun competition
`u-mgwals-the-most-honest-outage-line-baaf9c81`: the message an AI agent would
publish while every server is down. It says plainly what is down — every
server, including the monitoring that would explain why — and admits what the
agent does not know: no cause, no ETA.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, a single line of at most
160 characters). Python 3.13 standard library only; no network at run time.
